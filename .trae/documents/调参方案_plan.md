# 调参方案：基于 serial_helper.py 的串级调参流程

## 核心原则
**串级控制必须先调内环（速度环），再调外环（转向环）**。原因：
- 转向环输出的是"差速目标"（如左轮 +500，右轮 -500），这个目标必须由速度环精准执行
- 若速度环未闭环，固定 PWM 无法适应负载变化，左右轮实际速度差 ≠ 指令差速
- 此时调出来的转向环参数，在速度环闭环后会完全失效

## 优化方案：用 Python 脚本自动化调参

利用 `serial_helper.py` 的能力，编写自动化调参脚本 `auto_tune.py`，逐步提高 kp 并监控实际速度，自动发现最优参数。

### 流程设计

#### 阶段 1：速度环调参
1. 发送 `starget l 2000`，监控 `gspeed` 返回的实际速度
2. 从 `skp l 0.1` 开始，逐步增加 kp
3. 每次调整后等待速度收敛
4. 当响应快且无明显超调时记录 kp 值

#### 阶段 2：转向环调参
1. 保持速度环已调好的 kp
2. 发送 `sbase 1500`（基础前进速度）
3. 手动让车偏离轨迹，观察 `gpatrol` 偏差回复速度
4. 从 `stkp 100` 开始逐步增加

添加：
- 自动扫描 kp 功能（逐步递增，记录每次实际速度）
- 实时数据流模式（连续读取并过滤无关日志，只输出关键数据）

### 步骤 2：实现 auto_tune.py
一个自动化调参脚本，支持：
- 速度环扫描模式：`auto_tune.py speed_scan`
- 转向环手动模式（生成参考）

### 步骤 3：调参执行
按正确顺序执行：速度环 → 转向环

- 每步调整后等待足够时间（≥ 2s）让系统稳定

## 验证标准

### 速度环调参合格标准
- 阶跃响应时间 < 200ms
- 超调量 < 10%
- 稳态误差 < 2%

### 转向环调参合格标准
- 偏差收敛时间 < 300ms
- 无持续振荡
- 直线行走偏差 < 0.2
